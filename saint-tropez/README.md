# Saint Tropez Supermarket — website

Static site (HTML/CSS/JS, no build step). Open `index.html` in a browser, or deploy the folder to any static host (Vercel, Netlify, GitHub Pages).

## Sections
Header & mobile menu · Hero with live "open now" status · Departments · Weekly offers (filterable) · Delivery via WhatsApp · About · Hours & map · Contact form · Footer

## To customize
- `script.js` → `STORE` (WhatsApp number, currency, opening hours) and `OFFERS` (weekly deals).
- `index.html` → replace bracketed placeholders: `[Street address]`, `[Phone number]`, `[Email address]`, delivery area/minimum, social links, map query.
- `styles.css` → brand colors in `:root`.
